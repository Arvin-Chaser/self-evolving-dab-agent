# Current project structure

This repository currently tracks the DAB / DataAgentBench code-agent evolution pipeline as the active research mainline.

## Active mainline

- `experiments/run_dab_agent.py`  
  Runs one DAB data-agent case, builds the prompt, injects runtime observer/helper contracts, executes generated `solve.py`, and writes result/trace artifacts.

- `experiments/run_codex_qwen_repair_launcher.py`  
  Generates one isolated structured patch-spec candidate with Codex-Qwen, applies it deterministically, and runs candidate gates.

- `experiments/run_meta_agent_evolution_loop.py`  
  Runs the parent -> candidate -> child-eval -> archive loop.

- `experiments/build_meta_agent_evidence_pack.py`  
  Builds compact fine-grained feedback/evidence packs from data-agent runs.

- `experiments/analyze_agent_error.py` and `experiments/extract_primary_signal.py`  
  Analyze traces/results and select the primary failure signal.

- `experiments/run_codex_qwen_proxy_launcher.sh`  
  Local launcher wrapper for Codex-Qwen proxy mode.

## Active adapters

- `adapters/runtime_observer.py`  
  Runtime logging API injected into generated data-agent code.

- `adapters/feedback/`  
  Feedback/error-analysis infrastructure.

- `adapters/patents/`  
  Reusable PATENTS helper modules generated by tool-first data-agent repair candidates.

## Prompt and skill inputs

- `prompts/dab/dab_code_agent_prompt_v005_runtime_observer.txt`  
  Current data-agent prompt baseline.

- `skills/dab-meta-agent-project-memory/` and `skills/dab-patents-project-repair/`  
  Project-specific instructions for the meta-agent.

## Evolution records

- `archive/`  
  Long-lived agent/candidate indexes and selection metadata.

- `candidates/dab/`  
  Candidate patch bundles produced by meta-agent repair runs.

- `trajectories/meta_agent_loops/`  
  Loop-level parent/candidate/child-eval run records.

- `logs/dab_agent/`  
  Data-agent execution logs and fine-grained runtime traces.

## Historical / non-mainline

- `legacy/text2sql_demo/`  
  Early Text-to-SQL demo code. Not part of the active DAB research mainline.

- `legacy/dab_old_architecture_20260615/protocol_artifacts/`  
  Early one-off Codex-Qwen smoke tests, protocol gates, iter003 launchers, and first-candidate scripts. Preserved for reproducibility but not active entry points.

## Avoid treating as primary entry points

The following are kept for historical/reference compatibility unless explicitly needed:

- older prompt evolution scripts such as `experiments/run_self_evolve_loop.py`
- old autonomous/meta-agent prototype entry points under `experiments/` and `meta_agent/`
- archived logs and candidates from earlier experiments
