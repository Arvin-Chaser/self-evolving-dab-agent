# DAB Old Architecture Archive

This archive contains DAB/Text2SQL artifacts produced before the project moved
to the HyperAgent-style project-level meta-agent architecture.

Archived contents:

- `logs/`: old DAB runs, prompt-level self-evolve runs, dry runs, and manual
  signal/evaluation logs.
- `prompts/`: old object-level prompts, prompt-level evolution outputs, and
  meta-output files.

These files are kept for historical reference only. They should not be treated
as the current mainline implementation or as active evidence for new
project-level meta-agent experiments unless explicitly requested.

The current mainline prompt is:

```text
prompts/dab/dab_code_agent_prompt_v004_operation_trace.txt
```
